B2B (Enterprises & SaaS) — How to use Postal

B2B customers typically need multi-tenant isolation, dedicated IPs, SLA, and advanced deliverability controls. This section lists recommended steps and features for enterprise usage.

Key Requirements

  • Dedicated IP allocation and IP warmup scheduling.
  • Multi-org tenancy and role-based access control.
  • Per-organization rate limits, quotas, and invoice billing.
  • Detailed delivery analytics and domain-level reputation graphs.

Recommended Onboarding Flow

  1. Sign up and create an organization.
  2. Configure billing (Stripe) and purchase dedicated IP(s) if required.
  3. Add sending domains via the domain wizard and complete DKIM/SPF/DMARC checks.
  4. Create and distribute API keys to application teams (rotate regularly).
  5. Start sending through the edge intake; monitor warmup and reputation via dashboards.

Operations & Deliverability

B2B customers should use a hybrid delivery model: start on HTTP relay APIs for non-critical traffic, and migrate high-volume streams to dedicated MTA instances with dedicated IPs for the best control over reputation.

Security & Compliance

Enable Cloudflare Access for admin UI, require 2FA, and add automated abuse detection to pause suspicious activity.
