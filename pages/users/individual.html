Individual / Developer Users — How to use Postal

Developers and individual users want a simple, fast way to integrate email sending for apps, tests, or small projects.

Quick Start

  1. Get an API key from the dashboard (PoC: use x-api-key header for testing).
  2. Send a test message to verify integration:
curl -X POST https://your-pages-url/api/send \
  -H "Content-Type: application/json" \
  -H "x-api-key: test" \
  -d '{"from":"me@example.com","to":"you@example.com","subject":"hi","text":"hello"}'

Developer Tips

  • Use SDK snippets (Node/Python) to integrate quickly.
  • For local testing use wrangler dev and the local endpoints.
  • Use the domain wizard for sending from your own domain.

SDK Examples

Replace YOUR_API_KEY and https://your-pages-url with your values.

Node.js (native fetch)

// Node 18+ (or any runtime with fetch)
const payload = {
  from: 'me@example.com',
  to: 'you@example.com',
  subject: 'Hello from Node',
  text: 'Hi — this is a test.'
};

const res = await fetch('https://your-pages-url/api/send', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'YOUR_API_KEY'
  },
  body: JSON.stringify(payload)
});
const data = await res.json();
console.log(res.status, data);

Python (requests)

import requests

url = 'https://your-pages-url/api/send'
headers = {
    'Content-Type': 'application/json',
    'x-api-key': 'YOUR_API_KEY'
}
payload = {
    'from': 'me@example.com',
    'to': 'you@example.com',
    'subject': 'Hello from Python',
    'text': 'Hi — this is a test.'
}

resp = requests.post(url, headers=headers, json=payload)
try:
    print(resp.status_code, resp.json())
except ValueError:
    print(resp.status_code, resp.text)
